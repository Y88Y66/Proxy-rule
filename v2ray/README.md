# v2rayN and v2rayNG

This folder is reserved for routing rules in V2Ray/Xray JSON format.

The Shadowrocket configuration is not compatible with v2rayN or v2rayNG. When added, `routing.json` will use explicit `proxy` and `direct` outbound tags and will be maintained independently from `shadowrocket/default.conf`.

Do not store node subscriptions, server addresses, credentials, or complete client configurations in this public repository.
